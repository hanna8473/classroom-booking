# 기존 HTML 규칙 대조표

## 이전 비교 방법

- 두 HTML의 기준 사본에 실제 운영 연결이 들어 있으므로 실행 비교는 별도로 Firebase 호출을 가상 데이터에 연결한 검증 환경에서 수행한다. 실제 계정·비밀번호·학생 정보 없이 저장 전후 상태와 화면 결과를 함께 대조한다.
- 청소 배정에서 정렬 기준, 명단·구역 순서, 난수 호출 순서가 달라져도 결과가 달라질 수 있다. 비교 때는 날짜·명단 순서·난수 입력을 고정하고 요일 배정, 구역 배정, 수동 고정 상태, 통계, 경고 및 복구 결과를 대조한다.
- 기존 코멘트와 실행 분기가 다르면 실행 동작을 기준으로 확인한다. 대표 사례는 관리자 표의 시간 검사 경로, 달력 시작 요일 검사, 목요일 일반 한도와 활동 예외의 조합이다.
- 이 문서는 코드 검토 결과다. 실제 화면 실행, 기능별 비교 테스트, 운영 Firebase 설정 대조는 아직 수행하지 않았다.
